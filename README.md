# DSR-MO

> 面向 **CEC 2026 多模态优化基准** 的单目标 niching 算法 —— **D**iverse-**S**earch & **R**efine for **M**ultimodal **O**ptimization
>
> 语言：**[简体中文](README.md) | [English](README_EN.md)**

---

DSR-MO 是一个黑盒、策略无关的单目标多模态优化算法，核心思想是 **「先占地盘、后精耕细作」**：把「找全所有峰盆地」（离散覆盖）与「精确压到盆底」（连续收敛）两个难度分离，分别交给不同机制完成，而不是在单一目标函数上同时硬压两者。

> **🎯 定位：极低维度多模态优化算法（extremely low-dimensional MMO）**
>
> DSR-MO 专注 **D=2** 这一极低维度场景。设计哲学「先占地盘、后精耕细作」依赖**自估生态位半径**（无先知），该机制只在低维下可靠；高维（D≥5）会因「维度灾难」使点距趋同、自估半径失效。因此 DSR-MO 把所有精力压在对 D=2 这一现实且高频场景的极致优化上，不追求不切实际的高维泛化。

## 2. 想解决的问题

多模态优化（MMO）的核心矛盾是**找得全**与**找得准**不可兼得：

- **找得全**：把决策空间里全部等高的全局峰盆地都发现出来（离散覆盖）。
- **找得准**：每个峰都精确压到盆底，且不多报冗余解（连续收敛 + 紧凑报告）。

传统做法在单一目标函数上同时硬压两者，往往顾此失彼——强收敛会早熟合并到少数几个峰，强铺开又会丢失精确度。DSR-MO 的目标是**在不使用真峰位置（无先知）的前提下，同时做到高覆盖与高精度**。

## 3. 算法架构

DSR-MO 采用「搜索 + 精修 + 报告」三段式流水线，各模块职责单一、可独立替换：

```
初始化种群
   │  (拉丁超立方式随机采样)
   ▼
进化搜索（主循环）
   │  变异(SBX交叉 + 多项式变异) → 合并父代子代
   │  环境选择：fitness + maximin 最远点混合选择（保留等高峰）
   ▼
峰提取（每盆地一个代表）
   │  按目标排序 + 自估半径 clearing 去重
   ▼
局部精修（Nelder-Mead 无导数单纯形）
   │  D≥5 时 3× 随机扰动重启
   ▼
精修后函数值阈值过滤（剔除局部极小）
   ▼
报告期密度过滤（最终报告，无先知）
   │  简化密度聚类去冗余，每簇保留最优
   ▼
最终解集 X, F
```

**关键设计**：搜索阶段用 `maximin` 强制种群在决策空间铺开占位（保住覆盖），收敛精度完全交给后置的 Nelder-Mead 精修（保住 Precision）。两者解耦，互不拖累。

## 4. 核心机制与数学公式

### 4.1 环境选择：fitness + maximin 混合

每次迭代把父代与子代合并后，从候选集选回种群规模 $n$ 个个体。先保留目标最优个体，之后每次选「目标越好 + 离已选集合越远」得分最高的个体：

$$
\text{score}(x) \;=\; -\,\text{normF}(x)\;+\;\lambda\,\frac{d_{\min}(x)}{\mathrm{dom}}
$$

其中：

- $\text{normF}(x) = \dfrac{F(x) - F_{\min}}{F_{\max} - F_{\min}}$ —— 归一化目标值 $\in[0,1]$，越小越好。
- $d_{\min}(x) = \min_{s\in S} \lVert x - s \rVert$ —— 个体 $x$ 到「已选集合 $S$」的最近距离。
- $\mathrm{dom} = \sqrt{\dim}\cdot(\mathrm{ub}-\mathrm{lb})$ —— 决策空间对角线，用于归一化距离。
- $\lambda$ —— 多样性权重（默认 20），越大越重视决策空间足迹。

这一项同时兼顾收敛性（$-\text{normF}$）与多样性（$\lambda\, d_{\min}/\mathrm{dom}$），从而保留全部等高峰。

### 4.2 生态位去重（clearing，无先知）

峰提取时按目标排序，用生态位半径把疏远点判定为新峰：

$$
d(p,\; x_r) > r \quad\Longrightarrow\quad p \ \text{is a new peak representative}
$$

其中 $x_r$ 为任一已有代表点，$r$ 为生态位半径。**自估半径**不依赖真峰半径 `problem.nichRad`（避免先知）：

$$
r \;=\; \underset{\,i}{\operatorname{median}}\ \ \min_{j\neq i}\ \lVert x_i - x_j\rVert
$$

即取候选池「最近邻距离中位数」作为当前景观峰间距的估计，自适应、可复现。

### 4.3 局部精修：Nelder-Mead 无导数单纯形

对每个候选峰代表，从初始单纯形出发迭代反射(Reflect)→扩展(Expand)→收缩(Contract)→压缩(Shrink)，沿弯曲谷道（如 Rosenbrock）精确压到真全局峰。D≥5 时对每个代表做 3 次随机扰动重启，取最优结果，缓解对初始单纯形的敏感性。

### 4.4 报告期密度过滤（最终版）

对阈值过滤后的报告集做简化密度聚类（Union-Find 连通分量），每簇只保留目标最优的代表，消除「多报冗余」：

$$
\varepsilon \;=\; \underset{\,i}{\operatorname{median}}\ \ \min_{j\neq i}\ \lVert \hat{x}_i - \hat{x}_j\rVert, \qquad
\hat{x}_k \;=\; \underset{x \in C_k}{\operatorname{arg\,min}}\ F(x)
$$

其中 $\varepsilon$ 为自适应聚类半径（无先知），$C_k$ 为第 $k$ 个簇，每簇保留目标最优的点。

这一模块不带任何搜索核心改动，是正交的即插即用组件，是 Precision 从 0.756 → 0.992 的关键。

### 4.5 CEC 2026 评测指标

$$
\text{RPR} = \dfrac{N_{\text{found}}}{N_{\text{GM}}}, \qquad
\text{Precision} = \text{RPR}\cdot\dfrac{N_{\text{GM}}}{N_{\text{sol}}}, \qquad
\text{F1} = \dfrac{2\,\text{Precision}\cdot\text{RPR}}{\text{Precision}+\text{RPR}}
$$

$$
\text{Official Score} = \tfrac{1}{2}\big(\text{RPR}+\text{F1}\big)
$$

其中 $N_{\text{found}}$ 为命中的全局峰数，$N_{\text{GM}}$ 为真实全局峰总数，$N_{\text{sol}}$ 为报告的解个数。

## 5. 遇到的问题与解决

开发与评测过程中，DSR-MO 遇到并逐一解决了以下问题：

### 5.1 移植 bug（基准正确性）

| 问题 | 表现 | 解决 |
|---|---|---|
| **Weierstrass 漏平移项** | 漏了 `+0.5`，P07/P15 在真峰处求值偏差 1.8~5.2 | 补平移项，16 问题基准自检全部通过（maxDev=0） |
| **sequences.csv 索引越界** | 官方数据为 1-based，多加了 `+1`，D=5 时 `numUniform(10001)` 越界 | 修正索引，D=5 恢复可运行 |

### 5.2 算法设计问题

| 问题 | 表现 | 解决 |
|---|---|---|
| **精修后缺函数值过滤** | Ackley 返回大量局部极小候选，Precision 偏低 | 新增阈值过滤，Precision 显著提升 |
| **预算超标 + 先知半径** | 早期用 50000×dim 预算、真峰半径，不可对标官方 | 改为官方预算 20000×dim + 自估半径（无 Oracle） |
| **Nelder-Mead 高维敏感** | 对初始单纯形敏感，D≥5 收敛不稳 | D≥5 对每个代表做 3 次随机扰动重启，取最优 |
| **报告冗余拖低精度** | 同一盆地重复报告，Precision 仅 0.756 | 新增报告期密度过滤（`dsr_mo_density_filter.m`），Precision 提到 0.992，Coverage 无损 |

### 5.3 方法论洞察

对照实验（隔离 λ、预算、先知）揭示一条与直觉相反的经验：**在多模态搜索前期，个体目标值好坏远不如「是否离已探索区域足够远」重要**。λ=20 强制种群铺开占位，哪怕早期目标值很差，也能在搜索后期用无导数 Nelder-Mead 精修把收敛损失完全弥补回来。这就是「先占地盘、后精耕细作」成立的原因。

## 6. 与他人对比

DSR-MO 的定位，是在 **CEC 2026 多模态优化竞赛**这条最主流赛道上，正面挑战当年的**第一名**。我们不避讳这一点——比赛就得跟最强的人比。

> 为保持学术礼貌，这里不点名对手，仅以「CEC 2026 竞赛第一名」指代该赛事冠军算法（其论文：Chauhan & Dikshit，*S-CARD-CMSA: A Score-Aware Candidate Archive with Density-Filtered Reporting for Multimodal Optimization*, arXiv:2607.13764, 2026）。以下所有对比均在**尊重、公平、同口径**的前提下展开。

### 6.1 同环境实况复现对比（D=2，主结论）

为了公平，DSR-MO 在**同一台机器（MATLAB R2026a）、同一基准**下复现了第一名的开源实现，逐题逐实例（16 题 × 15 实例，预算 20,000×D）在 D=2 上真实跑了一遍，并用与 DSR-MO **完全相同**的评测口径（二分命中，相对容忍精度 1e-3）打分。复现实测数据如下（240 次独立运行，单次逐实例）：

| 指标 | 竞赛第一名（同环境复现，D=2） | **DSR-MO**（D=2，15 实例×5 次） |
|---|---|---|
| **Coverage / RPR** | **0.979** | 0.899 |
| **Precision** | 0.890 | **0.992** |
| **F1** | 0.916 | **0.935** |
| **官方得分 ½(RPR+F1)** | **0.947** | 0.917 |
| 成功覆盖率 SR | 0.742 | 0.538 |

**如实解读**：同环境复现证明，第一名在 D=2 上确实非常能打——尤其**覆盖能力（0.979）**明显强于 DSR-MO（0.899），这是它搜索引擎的优势，DSR-MO 坦率承认、也尊重。DSR-MO 的亮点则集中在**报告质量**：**Precision 0.992 与 F1 0.935 双双反超**，说明 DSR-MO 的密度过滤去冗余在「少报冗余、精准收口」上更极致。两者是典型的「搜索强覆盖 vs 报告精筛选」互补格局——这正是 DSR-MO 对照实验最想呈现的结论。

> **口径声明**：上表第一名数据为在 DSR-MO 作者的 MATLAB 环境（R2026a）下的逐实例单次复现，与 DSR-MO 用同一评测函数打分；DSR-MO 为跨 15 实例×5 次的均值。两者同为 D=2、20,000×D 预算，指标可直接对比。复现脚本见 `../复现_S-CARD-CMSA/run_reproduce_d2.m`。

**顺带提及**：其技术报告公布的官方数字（RPR 0.805 / Precision 0.915 / F1 0.831 / 官方分 0.818）为 768-run **跨维混合**均值，并非纯 D=2 全量，仅供了解其官方口径，不作为主结论依据——上面的同环境复现才是本文的对比基准。

### 6.2 机制对比

| 维度 | 竞赛第一名 | DSR-MO |
|---|---|---|
| 搜索引擎 | 协方差自适应演化策略 + 禁忌区排斥 | 种群进化 + fitness+maximin 选择 + Nelder-Mead 精修 |
| 多样性保持 | 主动子种群 + 存档禁忌区排斥已找峰 | maximin（离已选集越远越好）铺开占位 |
| 收敛机制 | 协方差矩阵自适应采样 | 无导数 Nelder-Mead 单纯形 |
| 报告阶段 | 被动二级存档 + 得分感知密度过滤 | 阈值过滤 + 简化密度聚类去冗余（无先知） |
| 使用真峰位置 | 否 | 否 |
| 核心哲学 | 搜索期原样 + 报告期精细筛选 | 搜索期强覆盖 + 报告期去冗余，两阶段都主动优化 |

**结论**：基于同环境复现数据（§6.1），DSR-MO 在报告（去冗余）阶段反超：Precision 0.992、F1 0.935 高于第一名（0.890 / 0.916）；DSR-MO 在搜索（找峰）阶段略逊（覆盖 0.899 < 0.979），但已如实呈现。两者形成「搜索强覆盖 vs 报告精筛选」的互补格局。

## 7. 快速开始

