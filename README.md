# DSR-MO

> 面向 **CEC 2026 多模态优化基准** 的单目标 niching 算法 —— **D**iverse-**S**earch & **R**efine for **M**ultimodal **O**ptimization
>
> 语言：**[简体中文](README.md) | [English](README_EN.md)**

---

DSR-MO 是一个黑盒、策略无关的单目标多模态优化算法。它的核心思想是 **「先占地盘、后精耕细作」**：把「找全所有峰盆地」（离散覆盖）与「精确压到盆底」（连续收敛）两个难度分离，分别交给不同机制去完成，而不是在单一目标函数上同时硬压两者。

在 CEC 2026 官方评测口径下（16 题 × 15 实例 × D=2，预算 20,000×D），DSR-MO 达到 **Coverage 0.899 / Precision 0.992 / F1 0.935 / 官方得分 0.917**，高于 S-CARD-CMSA（RS-CMSA-ESII + 密度过滤报告）论文公布的 0.818。

## 1. 特性与亮点

- **黑盒无先知**：不使用真峰位置做优化，生态位半径与报告密度过滤半径均从候选解**自估**，与 CEC 官方规则对齐。
- **找峰极强**：D=2 下 P05/P10/P11/P12/P13 常达全覆盖（Coverage/F1=1.000）。
- **精度高达 0.992**：报告期密度过滤把冗余报告压到 ≈ 真实峰数，绝大多数问题 Precision=1.000。
- **预算不敏感**：实证表明覆盖率并非靠堆预算而来，算法对评估预算稳健。
- **跨平台**：MATLAB 与 GNU Octave 下结果逐位一致（仅浮点舍入级差异）。
- **可复现**：一键运行 `run_dsr_mo` 即可生成全部结果。

## 2. 算法架构

DSR-MO 采用「搜索 + 精修 + 报告」三段式流水线，各模块职责单一、可独立替换：

```
初始化种群
   │  (拉丁超立方式随机采样)
   ▼
进化搜索（主循环）
   │  变异(SBX交叉 + 多项式变异) → 合并父代子代
   │  环境选择：fitness + maximin 最远点混合选择（保留等高峰）
   ▼
峰提取（每盆地一个代表）
   │  按目标排序 + 自估半径 clearing 去重
   ▼
局部精修（Nelder-Mead 无导数单纯形）
   │  D≥5 时 3× 随机扰动重启
   ▼
精修后函数值阈值过滤（剔除局部极小）
   ▼
报告期密度过滤（最终报告，无先知）
   │  简化密度聚类去冗余，每簇保留最优
   ▼
最终解集 X, F
```

**关键设计**：搜索阶段用 `maximin` 强制种群在决策空间铺开占位（保住覆盖），收敛精度完全交给后置的 Nelder-Mead 精修（保住 Precision）。两者解耦，互不拖累。

## 3. 核心机制与数学公式

### 3.1 环境选择：fitness + maximin 混合

每次迭代把父代与子代合并后，需要从候选集选回种群规模 `n` 个个体。先保留目标最优个体，之后每次选「目标越好 + 离已选集合越远」得分最高的个体：

```text
score(x) = -normF(x) + λ · (d_min(x) / dom)
```

其中：

- `normF(x) = (F(x) - F_min) / (F_max - F_min)` —— 归一化目标值（[0,1]，越小越好）。
- `d_min(x) = min_{s ∈ S} ‖x - s‖` —— 个体到「已选集合 S」的最近距离。
- `dom = √dim · (ub - lb)` —— 决策空间对角线，用于归一化距离。
- `λ` —— 多样性权重（默认 20），越大越重视决策空间足迹。

这一项同时兼顾收敛性（`-normF`）与多样性（`λ·d_min/dom`），从而保留全部等高峰。

### 3.2 生态位去重（clearing，无先知）

峰提取时按目标排序，用生态位半径把疏远点判定为新峰：

```text
若 d(p, 任一已有代表) > r  ⟹  p 是新峰代表
```

**自估半径**（不依赖真峰半径 `problem.nichRad`，避免先知）：

```text
r = median( 候选集中每个点的最近邻距离 )
```

即取候选池「最近邻距离中位数」作为当前景观峰间距的估计，自适应、可复现。

### 3.3 局部精修：Nelder-Mead 无导数单纯形

对每个候选峰代表，从初始单纯形出发迭代反射(Reflect)→扩展(Expand)→收缩(Contract)→压缩(Shrink)，沿弯曲谷道（如 Rosenbrock）精确压到真全局峰。D≥5 时对每个代表做 3 次随机扰动重启，取最优结果，缓解对初始单纯形的敏感性。

### 3.4 报告期密度过滤（最终版）

对阈值过滤后的报告集做简化密度聚类（Union-Find 连通分量），每簇只保留目标最优的代表，消除「多报冗余」：

```text
eps = median( 报告集最近邻距离中位数 )   % 自适应，无先知
每簇保留 argmin F(x) 的点
```

这一模块不带任何搜索核心改动，是正交的即插即用组件，是本版 Precision 从 0.756 → 0.992 的关键。

### 3.5 CEC 2026 评测指标

```text
RPR(recall) = N_found / N_GM                    % 找到的全局峰占比
Precision   = RPR · N_GM / N_sol                % 报告越紧凑越高
F1          = 2·Precision·RPR / (Precision+RPR)
官方得分    = ½ · (RPR + F1)
```

## 4. 方法论贡献

不同于传统进化算法强调「早熟收敛」，DSR-MO 实证揭示：**在多模态搜索前期，个体目标值好坏远不如「是否离已探索区域足够远」重要**。λ=20 强制种群在决策空间铺开占位，哪怕早期目标值很差，也能在搜索后期用无导数 Nelder-Mead 精修把收敛损失完全弥补回来。

这是一种「先占地盘、后精耕细作」的高效多模态策略——把离散覆盖与连续收敛两个难度分离，分别交给不同机制，而不是在单一目标函数上同时硬压两者。

## 8. 与 S-CARD-CMSA 的对比

> S-CARD-CMSA 是 RS-CMSA-ESII + 得分感知密度过滤报告框架，与 DSR-MO 同赛道（CEC 2026 多模态 niching）。

### 8.1 量化对比（D=2，同配置 20,000×D 预算）

| 指标 | S-CARD-CMSA（论文 768-run 校验） | DSR-MO（D=2，15 实例×5 次） |
|---|---|---|
| **Coverage / RPR** | 0.805 | **0.899** |
| **Precision** | 0.915 | **0.992** |
| **F1** | 0.831 | **0.935** |
| **官方得分 ½(RPR+F1)** | 0.818 | **0.917** |

**口径声明（诚信）**：S-CARD-CMSA 的 0.805/0.915/0.831/0.818 取自其论文 768-run **跨维混合**校验子集，非纯 D=2 官方全量；DSR-MO 为 D=2 全 16 题×15 实例×5 次。两者同规则（均 20,000×D 预算）但维度口径不完全一致，属**方向性对比**，不构成严格同工况。作者论文未按维度拆解报告，如需严格同工况可按学术惯例邮件索取或重跑其开源代码（`github.com/ChauhanDikshit`）。

### 8.2 机制对比

| 维度 | S-CARD-CMSA | DSR-MO |
|---|---|---|
| 搜索引擎 | 协方差自适应演化策略（RS-CMSA-ESII）+ 禁忌区排斥 | 种群进化 + fitness+maximin 选择 + Nelder-Mead 精修 |
| 多样性保持 | 主动子种群 + 存档禁忌区排斥已找峰 | maximin（离已选集越远越好）铺开占位 |
| 收敛机制 | 协方差矩阵自适应采样 | 无导数 Nelder-Mead 单纯形 |
| 报告阶段 | 被动二级存档 + 得分感知密度过滤 | 阈值过滤 + 简化密度聚类去冗余（无先知） |
| 使用真峰位置 | 否 | 否 |
| 核心哲学 | 搜索期原样 + 报告期精细筛选 | 搜索期强覆盖 + 报告期去冗余，两阶段都主动优化 |

**结论**：DSR-MO 在搜索（找峰）与报告（去冗余）两阶段均不落下风，官方得分 0.917 显著高于 0.818。
